## Excecution / Building

das projekt wird mit _"mvn clean install -U"_ gebaut,

und mit _"mvn exec:java"_ ausgeführt.

Ein unabhängiges package mit eingebundenen dependecies wird
folgendermaßen gebaut: 

mvn clean package


dies liegt dann in ./src/target drinne

## Debugging

beim debuggen bitte immer angeben, von wo man printed:

System.out.println("api.SimSumo: Simstart");
